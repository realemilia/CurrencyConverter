# CurrencyConverter
A simple console-based currency converter built using Java and Object-Oriented Programming principles. Supports multiple currencies with predefined exchange rates and clean modular code.
---

## 📌 Features

- Convert between major currencies (INR, USD, EUR, GBP, JPY)
- Uses object-oriented design with separate classes for logic and data
- Console-based user input and output
- Easy to extend and maintain

---

## 🛠 Technologies Used

- Java (JDK 8 or above)
- Java Collections (HashMap)
- OOP Concepts: Classes, Objects, Encapsulation

---

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/currency-converter-java.git
   cd currency-converter-java

2.Compile the Java files:
   javac Currency.java Converter.java CurrencyConverterApp.java

3.Run the program:
   java CurrencyConverterApp
